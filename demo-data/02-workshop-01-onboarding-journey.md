# Workshop 01 - Target Onboarding Journey

Date: 12 June 2026. Location: Meridian Bank, Canary Wharf. Facilitator: Priya
Raghavan (Northgate Advisory). Recording transcribed automatically, lightly
corrected for readability.

DANIEL OKAFOR (Head of Retail Product, Meridian Bank): Let me set the ambition.
Today a customer who wants a current account has to book a branch appointment or
fill in a web form that then dumps them into a branch appointment anyway. That
has to stop. A customer must be able to open a personal current account without
visiting a branch.

PRIYA RAGHAVAN (Engagement Lead, Northgate Advisory): End to end, including
identity checks?

DANIEL OKAFOR: End to end. If we cannot verify them digitally then yes, they get
routed to a branch, but that should be the exception, not the default path.

DANIEL OKAFOR: Second thing. We know a lot about our existing customers already.
If someone already banks with us for savings and they apply for a current
account, the system must pre-fill application data from the existing customer
record. Making them retype their address is how we lose people.

AISHA BELL (Customer Experience Lead, Meridian Bank): I want to add to that. The
customer must be able to save a partially completed application and resume it on
a different device within 14 days.

PRIYA RAGHAVAN: Fourteen days specifically?

AISHA BELL: Fourteen. That is what our retention team modelled. After fourteen
days the lead is cold anyway.

DANIEL OKAFOR: On status. Right now customers call the contact centre to ask
where their application is. The system must show the customer the current status
of their application and the expected completion date.

MARCUS TRAN (Branch Operations Manager, Meridian Bank): Branch staff need the
same view. If a customer walks in, the colleague in front of them must be able to
see exactly the same application status the customer sees.

PRIYA RAGHAVAN: Noted. Any hard rules about who can see what?

MARCUS TRAN: Branch colleagues should not be able to see the customer's credit
decision rationale, only the status. That is a compliance thing, Sofia can
confirm.

DANIEL OKAFOR: One more. When the account is activated it must appear in the
core banking platform within 15 minutes so the customer can use it immediately.

PRIYA RAGHAVAN: That is a hard integration requirement, I will take it to the
technical workshop.

AISHA BELL: And the journey has to work on a phone. Most of our applicants start
on mobile. The onboarding journey must be fully usable on a mobile browser
without installing an application.

DANIEL OKAFOR: Agreed. Mobile web first.
